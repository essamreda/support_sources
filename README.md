# مؤسسة مصادر الدعم للوساطة التمويلية

> حلول تمويلية واضحة وشفافة

## من نحن
وسيط تمويلي محايد يقف في صفّ طالب التمويل: نفهم وضعك المالي، نقارن لك الخيارات بوضوح، ونجهّز ملفك بشكل صحيح من المرة الأولى.
مبدأنا: **أن يعرف العميل بالضبط ما يوقّع عليه قبل أن يوقّع.**

## خدماتنا
- **التمويل الشخصي** — مقارنة العروض واختيار الأنسب لدخلك والتزاماتك.
- **التمويل العقاري** — مرافقة كاملة لشراء أو بناء أو إعادة تمويل العقار.
- **تمويل المنشآت** — حلول رأس المال العامل والتوسع للمنشآت الصغيرة والمتوسطة.
- **تمويل المركبات** — خيارات للسيارات الجديدة والمستعملة والمركبات التجارية.
- **إعادة التمويل** — مراجعة التزاماتك وتحسين شروطها أو جمعها في قسط واحد.
- **الاستشارات** — تقييم أولي وتجهيز ملفك قبل التقديم.

## آلية العمل
1. **تقديم الطلب** — نموذج مختصر بالبيانات الأساسية.
2. **دراسة الحالة** — مراجعة وضعك المالي وتحديد الخيارات.
3. **مقارنة العروض** — عرض البدائل بوضوح لتختار بوعي.
4. **المتابعة والإتمام** — تجهيز المستندات ومتابعة الطلب.

## التزامنا
- لا نطلب أي مقابل مقدم مقابل الاستشارة الأولية.
- لا نضمن الموافقة — القرار النهائي للجهة التمويلية.
- نوضّح التكلفة الإجمالية قبل أي التزام.
- لك حق الانسحاب في أي وقت قبل توقيع العقد.

## الأسئلة الشائعة
**هل تقدمون التمويل مباشرة؟** لا، نحن وسيط، والعقد النهائي مع الجهة التمويلية.
**كم تستغرق دراسة الطلب؟** غالبًا ٢٤–٧٢ ساعة، حسب اكتمال المستندات.
**هل بياناتي محمية؟** نعم، لا نشاركها إلا بموافقتك وبالقدر اللازم.
**هل توجد رسوم؟** الاستشارة الأولية بدون مقابل، وأي رسوم أخرى تُوضَّح كتابةً.
